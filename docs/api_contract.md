# API Contract

Base URL: `http://localhost:8000` (or your deployment host)
Docs: `http://localhost:8000/docs` (Swagger UI, auto-generated by FastAPI)

All requests and responses are JSON unless noted. Errors are returned as:

```json
{"code": "ERROR_CODE", "message": "Human readable message", "findings": []}
```

## Authentication

### POST /auth/login

Exchange a username and password for a bearer token.

```bash
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}'
```

Response:

```json
{"token": "...", "user": "admin", "role": "admin"}
```

Send the token as `Authorization: Bearer <token>` on all other endpoints. Auth is pluggable: set `auth_required` in `config.json` to enforce it.

### GET /health

Health probe.

```bash
curl http://localhost:8000/health
```

Response: `{"status": "ok"}`

## Session states

```
created → data_loaded → needs_input | understood → researched → options_ready → decided → deck_ready
                └────────────────────→ blocked
```

| Status | Meaning |
|---|---|
| `created` | Session exists, no data uploaded |
| `data_loaded` | Data uploaded and profiled |
| `needs_input` | The agent needs answers to clarifying questions |
| `understood` | The intent is confirmed, ready to generate options |
| `options_ready` | Three options generated and scored |
| `decided` | A recommendation is available |
| `deck_ready` | The `.pptx` deck has been built |
| `blocked` | The session cannot continue (error) |

## Question object

Returned by `POST /sessions/{id}/problem` when `status` is `needs_input`.

```json
{
  "id": "metric",
  "field": "metric",
  "text": "Which column is the metric?",
  "kind": "choice",
  "options": ["sales", "returns"],
  "required": true
}
```

- `kind`: `choice` (pick from `options`) or `text` (free text).
- `options`: real column names or group names taken from the data.
- The same question id is never asked twice.
- At most 3 questions are returned per request.

## Decision object

Returned by `GET /sessions/{id}/decision`.

```json
{
  "status": "decided",
  "problem_type": {"type": "improve", "confidence": 0.85, "reason": "asks why"},
  "user_intent": {"problem": "Reduce returns", "goal": "reduce", "metric": "returns", "group": "store"},
  "options": [
    {"name": "Target West", "summary": "...", "est_effect": "-20%",
     "impact": 5, "cost": 4, "risk": 3, "speed": 3, "score": 3.55}
  ],
  "best": 0,
  "reason": "Target West leads Copy East on lower cost, lower risk, speed.",
  "confidence": {"label": "High", "wins": 5, "total": 6, "alternative": null,
                 "evidence_strength": 2},
  "why_not": {"1": "Copy East loses on lower cost, lower risk, speed."},
  "tie": false,
  "evidence_strength": 2,
  "findings": []
}
```

## Endpoints

### POST /sessions

Create a session.

```bash
curl -X POST http://localhost:8000/sessions
```

### POST /sessions/{id}/data

Upload a CSV/Excel/JSON file (multipart form field `file`).

```bash
curl -X POST http://localhost:8000/sessions/<id>/data \
  -F "file=@workers_sample_data.csv"
```

### POST /sessions/{id}/scrape

Scrape a web table/list and store it as the session data (multipart form fields `url` and `selector`).

```bash
curl -X POST http://localhost:8000/sessions/<id>/scrape \
  -F "url=https://www.w3schools.com/html/html_tables.asp" \
  -F "selector=table tr"
```

### POST /sessions/{id}/problem

Submit the problem statement in plain words.

```bash
curl -X POST http://localhost:8000/sessions/<id>/problem \
  -H "Content-Type: application/json" \
  -d '{"text": "we pay too much overtime and need a plan"}'
```

### POST /sessions/{id}/answers

Answer clarifying questions.

```bash
curl -X POST http://localhost:8000/sessions/<id>/answers \
  -H "Content-Type: application/json" \
  -d '{"answers": {"goal": "reduce", "metric": "overtime_hours"}}'
```

### POST /sessions/{id}/confirm

Confirm or edit the understood intent.

```bash
curl -X POST http://localhost:8000/sessions/<id>/confirm \
  -H "Content-Type: application/json" \
  -d '{"edits": {"metric": "overtime_hours"}}'
```

### POST /sessions/{id}/options

Generate the three options. Body: `{"use_ai": false}`.

```bash
curl -X POST http://localhost:8000/sessions/<id>/options \
  -H "Content-Type: application/json" \
  -d '{"use_ai": false}'
```

### PATCH /sessions/{id}/ratings

Update ratings/weights; re-scores and re-checks confidence.

```bash
curl -X PATCH http://localhost:8000/sessions/<id>/ratings \
  -H "Content-Type: application/json" \
  -d '{"option_ratings": {"0": {"impact": 5, "cost": 1, "risk": 1, "speed": 5}},
       "weights": {"impact": 0.4, "cost": 0.25, "risk": 0.2, "speed": 0.15}}'
```

### GET /sessions/{id}/decision

Return the decision object.

```bash
curl http://localhost:8000/sessions/<id>/decision
```

### POST /sessions/{id}/deck

Build the deck. **Call this before downloading.** Optionally upload a branded `.pptx` template.

```bash
curl -X POST http://localhost:8000/sessions/<id>/deck
```

### GET /sessions/{id}/deck.pptx

Download the built deck. Always call `POST /deck` first; otherwise this returns `404`.

```bash
curl -OJ http://localhost:8000/sessions/<id>/deck.pptx
```

### GET /sessions/{id}/audit

Return guardrail findings for the session.

```bash
curl http://localhost:8000/sessions/<id>/audit
```

### POST /sessions/{id}/research

Run external deep research (search, fetch, extract, verify). Returns themes, findings, sources and coverage.

```bash
curl -X POST http://localhost:8000/sessions/<id>/research
```

Response:

```json
{
  "status": "ok",
  "themes": {"causes": ["F1"], "good_practices": ["F2"], "benchmarks": [], "risks": []},
  "findings": [{"id": "F1", "claim": "...", "source_url": "https://...",
                "title": "...", "retrieved_date": "2026-11-04", "supporting_snippet": "..."}],
  "sources": [{"number": 1, "title": "...", "url": "https://...", "retrieved_date": "2026-11-04"}],
  "coverage": 1.0,
  "message": "",
  "kept": 4,
  "dropped": 2,
  "model_calls": 3,
  "page_errors": []
}
```

- Sources are deduplicated by URL and numbered; findings reference those numbers.
- Findings whose snippet is not found in the page are dropped.
- `page_errors` lists pages skipped by robots.txt, timeouts or HTTP errors.
- If research is unavailable or partial, the deck says so and falls back to data-only options.

### GET /sessions/{id}/sources

Return the verified sources found for the session.

```bash
curl http://localhost:8000/sessions/<id>/sources
```

Response:

```json
{"status": "researched", "sources": [{"number": 1, "title": "...", "url": "https://...", "retrieved_date": "2026-11-04"}]}
```

## Authentication

Auth is a pluggable bearer-token dependency. When `auth_required` is `true` in `config.json`, send:

```bash
-H "Authorization: Bearer <token>"
```

Tokens are created with the existing `core.auth` module (`auth.make_token(username)`); no auth logic is duplicated.
